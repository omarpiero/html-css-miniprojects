Consigna de Mini Proyectos: HTML5 y CSS3

Especificaciones técnicas, estándares de maquetación y modalidad de entrega en GitHub para los 5 ejercicios prácticos de la asignatura.

1. Directrices Generales y Estándar de Entrega

La presente consigna establece los requisitos técnicos, de maquetación y de entrega para la serie de 5 mini proyectos de Desarrollo Web Front-End (HTML5 y CSS3). Cada estudiante o equipo debe desarrollar los proyectos de manera incremental, aplicando buenas prácticas de código limpio y semántico.

📋 Normas Generales de Entrega

  • Control de Versiones y GitHub: Todos los proyectos deben ser publicados en un único repositorio público de GitHub denominado html-css-miniprojects. Cada ejercicio debe estar alojado en su carpeta correspondiente (ej. /ejercicio-01/).
  • Modalidad de Entrega en Aula Virtual: El estudiante subirá al Aula Virtual un archivo de texto en formato Markdown (entrega_proyectos.md) o PDF que contenga el enlace principal al repositorio de GitHub y los enlaces directos a las carpetas de cada ejercicio.
  • Estándar de Código: Uso obligatorio de HTML5 semántico (sin divitis), separación total de estructura (HTML) y presentación (CSS), archivos CSS externos vinculados correctamente, y sangrado/indentación de 2 o 4 espacios.
  • Despliegue Opcional/Recomendado: Se evaluará positivamente la activación de GitHub Pages para la previsualización directa de cada proyecto.

2. Especificaciones de los 5 Ejercicios Prácticos

Ejercicio 01: Tarjeta de Presentación Personal (Perfil Digital)

📁 Estructura en repositorio: html-css-miniprojects/ejercicio-01/index.html y css/styles.css

Contenido Exigido:

  1. HTML Semántico: Uso correcto de etiquetas de estructura principal (<header>, <main>, <section>, <footer>).
  2. Manejo del Modelo de Caja (Box Model): Aplicación explícita de margin, padding, border y border-radius para crear una tarjeta de perfil redondeada y centrada.
  3. Multimedia y Tipografía: Inclusión de imagen de avatar recortada circularmente (object-fit: cover) y vinculación de fuentes desde Google Fonts.
### Criterios de Aceptación (Gherkin / BDD):

DADO que el usuario abre la página en el navegador

CUANDO se renderiza el archivo index.html

ENTONCES se visualiza una tarjeta centrada en pantalla con avatar circular, nombre completo en <h1>, biografía corta, lista de habilidades y enlaces a redes sociales.

#### Estructura CSS Clave Requerida

.profile-card { max-width: 380px; margin: 40px auto; padding: 24px; border-radius: 12px; }

.avatar { width: 120px; height: 120px; border-radius: 50%; object-fit: cover; }

Ejercicio 02: Página de Receta de Cocina Interactiva

📁 Estructura en repositorio: html-css-miniprojects/ejercicio-02/index.html y css/styles.css

Contenido Exigido:

  1. Estructuración de Listas y Tablas: Uso de listas no ordenadas (<ul>) para ingredientes con checkboxes personalizados, listas ordenadas (<ol>) para los pasos, y una tabla (<table>) estructurada con <thead> y <tbody> para valores nutricionales.
  2. Estilos de Interacción y Pseudo-clases: Resaltado de ítems mediante :hover, diferenciación de líneas de la tabla con filas alternadas (zebra striping con :nth-child(even)) y estilizado de elementos de foco.
Elemento HTML Requisito CSS Obligatorio Comportamiento Esperado
<table class="nutrition-table"> border-collapse: collapse; width: 100%; Bordes colapsados limpios y tabla adaptada al ancho del contenedor.
<tr:nth-child(even)> background-color: #F8F9FA; Lectura ágil con filas en tonos alternados de gris claro.
<li:hover> (Ingredientes) background-color: #E9ECEF; transition: 0.2s; Feedback visual cuando el cursor pasa sobre un paso o ingrediente.

Ejercicio 03: Landing Page de Producto / Servicio (Flexbox Layout)

📁 Estructura en repositorio: html-css-miniprojects/ejercicio-03/index.html y css/styles.css

Contenido Exigido:

  1. Navegación y Cabecera Flexible: Barra de navegación horizontal construida con display: flex, justify-content: space-between y align-items: center.
  2. Sección Hero (Principal): Bloque de impacto visual centrado con titular, bajada descriptiva y botón Call-to-Action (CTA) estilizado.
  3. Sección de Características (Features): Disposición de 3 tarjetas alineadas horizontalmente mediante Flexbox (flex-direction: row, gap y flex: 1).
-- Esquema de Maquetación Flexbox Requerido en CSS

.navbar { display: flex; justify-content: space-between; align-items: center; padding: 1rem 2rem; }

.features-grid { display: flex; gap: 20px; flex-wrap: wrap; }

.feature-card { flex: 1 1 280px; padding: 20px; background: #FFFFFF; border-radius: 8px; }

Ejercicio 04: Galería de Portafolio Adaptable (CSS Grid & Responsive)

📁 Estructura en repositorio: html-css-miniprojects/ejercicio-04/index.html y css/styles.css

Contenido Exigido:

  1. Grilla Fluid CSS Grid: Implementación de display: grid con grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)) para un diseño responsivo automático sin romper filas.
  2. Tratamiento de Imágenes: Uso estricto de width: 100%, height: 200px y object-fit: cover para garantizar una uniforme presentación de imágenes.
  3. Efectos Micro-interactivos: Animación en transiciones con transition: transform 0.3s ease y zoom suave en hover (transform: scale(1.03)).
Requisito de Adaptabilidad: El proyecto debe incluir al menos una regla de Media Queries (@media (max-width: 768px)) para ajustar márgenes, tamaños de fuente y padding en pantallas pequeñas.

Ejercicio 05: Componente de Tabla de Precios (Pricing Cards con Variables CSS)

📁 Estructura en repositorio: html-css-miniprojects/ejercicio-05/index.html y css/styles.css

Contenido Exigido:

  1. Variables CSS (Custom Properties): Declaración de paleta de colores, fuentes y espaciados en el bloque :root y reutilización mediante var(--nombre-variable).
  2. Destacado Visual de Tarjeta Principal: Tres planes (Básico, Pro, Enterprise) donde el plan "Pro" o recomendado destaca mediante escalado (transform: scale(1.05)), borde diferencial e insignia "Más Popular" posicionada con position: absolute.
  3. Botones y Estados de Interacción: Botones interactivos con cambios de fondo y sombra dinámica (box-shadow) en hover y active.
/* Declaración de Variables CSS Obligatoria */

:root {

--primary-color: #6802C1;

--accent-color: #63AEE6;

--text-dark: #212322;

--bg-light: #F8F9FA;

--radius-card: 10px;

}

3. Matriz y Rúbrica de Evaluación

Cada uno de los 5 ejercicios tiene un peso equivalente al 20% de la calificación total del bloque práctico. La evaluación se guiará por la siguiente escala multidimensional:

Criterio de Evaluación Excelente (100%) En Proceso (70%) Requiere Mejora (40%)
Semántica HTML5 Uso impecable de etiquetas semánticas según su propósito estructural. Sin etiquetas obsoletas. Uso aceptable de HTML5, pero incluye algunos contenedores <div> innecesarios. Estructura basada exclusivamente en <div> y <span> sin valor semántico.
Layouts CSS (Flexbox / Grid) Uso correcto y fluido de Flexbox y/o CSS Grid. Diseño responsive funcional en móviles y desktop. Maquetación correcta pero con problemas de desbordamiento o desalineación en ciertas pantallas. Uso de floats o posicionamiento absoluto inadecuado para la maquetación general.
Diseño Visual y UX Estética cuidada, contraste accesible, jerarquía tipográfica clara y uso armónico del modelo de caja. Diseño básico, márgenes desiguales o falta de contraste en algunos textos secundario. Apariencia sin estilizar, desproporcionada o con elementos colapsados.
Estructura en GitHub Repositorio ordenado, nombres de carpetas y archivos exactos a la consigna, commit mensajes claros. Repositorio creado, pero con nombres de carpetas imprecisos o desorden de archivos CSS. Archivos subidos sin estructura de carpetas o enlaces RLS incompletos.
